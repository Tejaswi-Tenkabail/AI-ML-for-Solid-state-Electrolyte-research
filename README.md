INSTRUCTIONS:

1) In the releases, you will find the lates version of sse-discovery software.

2) Download the file named installers.zip and extract it.

3) VERY IMPORTANT: You will observe that I have also included the installer for Python 3.12.9 (64 bit). PLEASE INSTALL THIS even if you have the latest version of Python as some simulations like CHGNET requires this version specifically( you don`t need to add this version of python to your path.)

4) After Python is installed, use the installation setup provided in the zip folder to install the software wherever you like it.

5) Now you can open the exe file titled 'sse-discover.exe' under the folder named 'sse-discover'.

6) When the software first launches, you will get a popup window with three different tabs named API key, Simulation tools and Models.

7) For API key go to https://next-gen.materialsproject.org/ , sign up for a free account and then go to your profile and get the API key and paste it into the space given in the software.

8) After you insert the key, test it. There is a small button called Test key. Please don`t worry if the software doesn`t respond for a few seconds. It is normal.

9) Once the test finishes you will get a check mark below the tabs like this: <img width="180" height="20" alt="Screenshot 2026-10-17 005724" src="https://github.com/user-attachments/assets/edfc75a5-3955-48f5-8194-95cc2f18abd5" />

10) Then go to the Simulation tools and press the 'Install simulation tools' tab.

11) The tools will be downloaded and installed after some time depending on your internet speed and your storage speed.

12) Then you can close the window by clicking on the done button or the close button on top-right.

13) Voila! Now you can start simulating.

14) Create a new project and then on the right-hand side, you can toggle the settings on and off.

15) Once you are satisfied with your settings, click the run button on the top.

16) Depending on your settings, the program might take some few minutes....or some few hours too. No need to worry though. There will be a progress bar.

17) Once it is finished, you can view the results, save your results as a csv file and analyse the data.

18) Boom~ Now you can go on simulating.
